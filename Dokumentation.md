# French Memory Game – Dokumentation

## Grobplanung

Wir entwickeln ein französisches Memory-Spiel mit der Game Engine **Godot**.
Godot ermöglicht eine schnellere und übersichtlichere Umsetzung als beispielsweise Windows Forms und bietet gleichzeitig bessere Möglichkeiten für ein ansprechendes und einheitliches Design.

## Anforderungen

* [ ] Funktionierendes Memory-Spiel
* [ ] Zufällige Anordnung der Memory-Karten in jeder Runde
* [ ] Möglichkeit, eigene Begriffe und Bilder hinzuzufügen
* [ ] Einheitliches und übersichtliches Design
* [ ] Mehrere Spielmodi

## Erweiterte Anforderungen

* [ ] Belohnungssystem
* [ ] Levelsystem, um das Lernen abwechslungsreicher und motivierender zu gestalten
* [ ] Speicherung des Spielfortschritts
* [ ] Möglichkeit, verschiedene Themenbereiche bzw. Vokabelsets auszuwählen
