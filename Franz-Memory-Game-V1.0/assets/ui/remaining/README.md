# Zusätzliche Pixel-Art-Buttons

Die PNG-Dateien in diesem Ordner sind eigenständige Sprites mit transparentem Hintergrund. Alle breiten Buttons sind wie die ursprünglichen Vorlagen 50×25 Pixel groß; die beiden Symbolbuttons sind 27×25 Pixel groß. Die Übersicht zeigt sie vierfach vergrößert mit Nearest-Filter.

- Blau (Navigation): `zurueck.png`, `weiter.png`, `menue.png`, `abbrechen.png`
- Orange (Hinzufügen/Eingabe): `manuell_eingeben.png`, `leeres_feld.png`, `neues_set.png`, `wortpaar_hinzufuegen.png`
- Grün (Speichern): `set_speichern.png`
- Rosa (Vokabelsets): `beispielset.png`, `set_vorlage.png`
- Rot (Entfernen): `entfernen.png`

`set_vorlage.png` ist absichtlich ohne Text, damit dynamische Set-Namen darüber angezeigt werden können. `generate_buttons.py` erzeugt die Sprites erneut; die bisherigen Menü-Buttons bleiben unverändert.
